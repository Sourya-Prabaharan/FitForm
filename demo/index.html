Joint Angle Trigonometry

Calculates 3D interior angles between three keypoint vectors (A, B, C) via dot product and Euclidean norm:

def angle(a: Point, b: Point, c: Point) -> float: v1 = (a.x - b.x, a.y - b.y, a.z - b.z) v2 = (c.x - b.x, c.y - b.y, c.z - b.z) dot = sum(p * q for p, q in zip(v1, v2)) mag = (norm(v1) * norm(v2)) return degrees(acos(clamp(dot / mag, -1, 1)))

Rep Peak & Trough Segmentation

Identifies repetition boundaries by detecting inflection troughs below exercise-specific biomechanical thresholds:

def rep_count_by_troughs(angles, bottom_th, top_th): smoothed = moving_average(angles, window=7) reps, saw_bottom = 0, False for v in smoothed: if v < bottom_th: saw_bottom = True if saw_bottom and v > top_th: reps += 1 saw_bottom = False return reps

Fatigue & Velocity Decay Modeling

Compares early vs. late concentric velocity, range of motion shrinkage, and path instability:

def percent_drop(early: float, late: float) -> float: if early <= 0: return 0.0 drop = (early - late) / early return round(max(0.0, min(100.0, drop * 100)), 1) # Triggers fatigue flag when decay > 25%
